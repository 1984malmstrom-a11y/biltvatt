# Station V2 assets

- V2.3 uses `public/preem-logo-review.png`, copied without edits from the local candidate that visually matches the logo the station manager showed in chat. The local candidate originally came from a third-party public repository; it has not been independently verified as an official Preem file. The station manager explicitly approved use of this exact V2.3 logo asset for publication on 2026-10-10. Earlier Git history and visual-review screenshots alone do not prove approval.
- `public/ferrari-campaign-original.png` is the exact, unmodified PNG supplied by the station manager in `Tanka bil, få Ferrari-godis (1).zip`. The file is 2172 × 724 pixels and has SHA-256 `59a6d075e98050d2e6cfcc1cb0c9db2cf70772b4bf34898e0430475032bf85a1`. The dashboard uses `object-fit: contain`; the monthly figures button is in the sales card, leaving the campaign card free of controls. A pop-out layer was not added because the supplied image is opaque and extracting a bag over the already visible bag risks a duplicated edge.
- `public/station-sunrise.webp` is an older generic illustration retained in the repository but no longer referenced by the dashboard. It does not depict the actual Tingsryd station.
- `public/fonts/caveat-latin-500-normal.woff2` is Caveat 500 Latin from `@fontsource/caveat` 5.3.0. It is self-hosted for the dashboard's handwritten accents under the [SIL Open Font License](licenses/Caveat-OFL.txt).
