# Station V2 assets

- The previous `public/preem-logo.png` came from a third-party public repository, without documented brand approval or usage rights. It has been removed from active assets. Both station headers use the earlier neutral star placeholder in the same logo slot. An official logo may only be restored after approval and a licensed file are supplied. Earlier Git history and visual-review screenshots still contain the old logo and must not be treated as proof of approval.
- `public/station-sunrise.webp` is an AI generated generic station illustration, 1600 pixels wide and about 100 KB. It is labeled as an illustration in the dashboard and does not depict the actual Tingsryd station. Replace it with an approved station photo when available.
- `public/fonts/caveat-latin-500-normal.woff2` is Caveat 500 Latin from `@fontsource/caveat` 5.3.0. It is self-hosted for the dashboard's handwritten accents under the [SIL Open Font License](licenses/Caveat-OFL.txt).
